# SolidWorks MCP 2021 Skill

This repository contains a Codex Skill that teaches an AI assistant to use a SolidWorks MCP server for CAD modeling and verification on SolidWorks 2021.

The Skill is at [`skills/solidworks-mcp-2021/SKILL.md`](skills/solidworks-mcp-2021/SKILL.md). It does not include or install the MCP server. Configure a compatible SolidWorks MCP adapter and its C# execution layer separately before using the Skill.

## Install

Install the Skill from this repository with the Codex skill installer using:

```text
repo: LiGaoT/Solidworks-MCP2021
path: skills/solidworks-mcp-2021
```

Alternatively, place the `skills/solidworks-mcp-2021` folder under your Codex skills directory and start a new chat. The Skill is guidance for the assistant; it does not replace live SolidWorks 2021 testing.
